# PT Lingo

Pass the NPTE. — React 18 + Vite 5 + Supabase + Tailwind CSS.

## Dev

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Installing as a PWA

### iOS (Safari)

1. Open the app in Safari on your iPhone or iPad.
2. Tap the **Share** button (box with arrow pointing up).
3. Scroll down and tap **Add to Home Screen**.
4. Tap **Add** — the app icon will appear on your home screen.

The app runs in standalone mode (no browser chrome) with a dark status bar.

### Android (Chrome)

1. Open the app in Chrome.
2. Tap the three-dot menu → **Add to Home Screen** (or look for the install banner).
3. Tap **Install**.

### Desktop (Chrome / Edge)

1. Open the app in Chrome or Edge.
2. Click the install icon in the address bar (or go to menu → **Install PT Lingo**).
3. Click **Install**.
